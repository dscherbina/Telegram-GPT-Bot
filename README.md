# Telegram-бот з ChatGPT

Telegram-бот на aiogram 3 з інтеграцією ChatGPT.

## Функціональність

- `/random` — випадковий факт від ChatGPT
- `/gpt` — вільний діалог із ChatGPT
- `/talk` — діалог від імені відомої особистості (Курт Кобейн, Стівен
  Гокінг, Фрідріх Ніцше, Єлизавета II, Джон Толкін)
- `/quiz` — вікторина з вибором теми та підрахунком балів
- `/translate` — переклад тексту на обрану мову
- Розпізнавання зображень — надішли фото, бот опише, що на ньому

## Технології

- Python 3.12, aiogram 3
- OpenAI Chat Completions API
- FSM (машина станів) для багатокрокових сценаріїв
- Логування дій користувача в консоль і файл

## Встановлення

1. Клонуй репозиторій і встанови залежності:
```bash
   pip install -r requirements.txt
```

2. Скопіюй `.env.example` у `.env` і заповни змінні:

- BOT_API_KEY=токен від @BotFather
- OPENAI_API_KEY=твій ключ
- OPENAI_BASE_URL=адреса сервера (якщо потрібна)
- OPENAI_MODEL=назва моделі

3. Запусти бота:
```bash
   python main.py
```

## Структура проекту
```
main.py              # точка входу
config.py            # налаштування з .env
gpt.py                # клієнт OpenAI
utils.py              # допоміжні функції
handlers/             # обробники команд і сценаріїв
keyboards/            # inline та reply клавіатури
resources/
    images/           # зображення для сценаріїв
    messages/         # тексти повідомлень
    prompts/          # системні промпти для ChatGPT
```
